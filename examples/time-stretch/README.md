# Time stretch

This 64-row, one-pattern song compares the same sample at normal, slow, and
fast durations using pitch-preserving time stretch. It uses sample `01` from
the shared demo WAV set.

- Row `00`: `C-4 01 RRR80` plays at normal duration.
- Row `08`: `C-4 01 RRR00` stretches to about four times the duration while
  keeping the pitch.
- Row `20`: `C-4 01 RRRFF` plays at about one quarter the normal duration.
- Song settings: 110 BPM, four rows per beat, twelve ticks per row.

The normal sample lasts about 0.8 seconds. The slow version starts at row `08`
and runs for about 3.1 seconds; row `20` starts the fast version after it has
finished. Let the pattern play through to compare all three.
