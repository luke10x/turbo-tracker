# DX7 chord progression

This example plays a four-chord progression with the built-in DX7 synth. One
64-row pattern contains four 16-row sections, one chord per section. Four
channels play the chord tones together, using the same embedded six-carrier
DX7 patch for a clear, full sound; no sample files are needed.

The progression is Cmaj7 (rows 00–0F), Am7 (10–1F), Fmaj7 (20–2F), and G7
(30–3F). Each chord starts on the first row of its section and sustains until
the next chord replaces it. At 100 BPM and four ticks per row, the full
pattern takes about 9.6 seconds to play and then loops.
