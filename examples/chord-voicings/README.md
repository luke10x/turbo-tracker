# Chord voicings

This is a non-effect feature example. Each chord is entered across four channels: the first channel plays its root, and the channels to its right use `+=4`, `+=3`, and `+=4` to build a major seventh voicing. The roots change over the progression, while the interval pattern stays the same.

Relative notes in normal pattern rows use the sounding note from the channel immediately to the left. Chaining offsets lets you define each chord tone from the previous one.
