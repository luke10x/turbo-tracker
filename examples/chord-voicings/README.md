# Chord voicings

This is a non-effect feature example. Each chord is entered across four channels: the first channel plays its root, and the channels to its right use `>04`, `>03`, and `>04` to build a major seventh voicing. Each `>` note adds its semitone count to the note in the channel immediately to its left on the same row.

The roots change over the progression, while the interval pattern stays the same. Use `+01` or `-01` when the reference should be the last note in the same channel instead.
