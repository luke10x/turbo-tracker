# SLC8B scale

This song plays a C-major scale from `SLC8B` of `tgndshtn-part1.wav`.
Each note is spaced two rows apart so the 8B slice, about 156 ms long, can
finish before the next note.

Slice 8 has an independent `+12` semitone note offset, so C-5 plays it at its
estimated C-5 root while the sample's overall reference remains C-4. The
scale is C-5, D-5, E-5, F-5, G-5, A-5, B-5, C-6.

The song uses 120 BPM, four rows per beat, and twelve ticks per row.
