# Same-channel note steps

In pattern rows, `+01` adds one semitone to the last resolved note in that same channel; `-02` subtracts two. The chain can continue across empty rows, and a new absolute note starts a new reference.

This short sine-wave pattern plays C-4, C#-4, D-4, then returns to C-4. All notes use channel 1 so the example isolates same-channel offsets.
