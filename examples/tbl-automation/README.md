# Table automation

Ticks `00`–`06` sweep volume (`MVL`), pan (`PAN`), and vibrato (`VIB`). Notes at ticks `00`, `04`, `08`, and `0C` use `SLC` ranges `05`, `5A`, `AF`, and `F0` to step through different sample slices. The table lets these effect changes be sequenced one tick at a time. Pattern row `0C` sends `OFF` to stop playback.
