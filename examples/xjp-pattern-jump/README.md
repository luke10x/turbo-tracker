# Pattern jump (XJP)

This is an ordinary song order with three patterns. Pattern `00` plays `C-4`, then `XJP02` at row `04` jumps to pattern `02`. Pattern `01` would play `E-4`, but is skipped; the target pattern starts `G-4`. The jump uses pattern number `02` in both Pattern and Song modes (in Song mode it selects the next active order that refers to that pattern).
