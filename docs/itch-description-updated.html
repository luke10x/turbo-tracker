Effects

Signature effect #1: SLC — Slice

16 ordered markers make 15 slices of the sample. The note and the effect are independent, unlike other trackers, which split the break into a single piano-roll sequence and take away pitch control. I use the SLC effect for slicing — the note is the actual note.

  • A note controls pitch of the region between two markers; each slice can override the reference note.
  • The SLC effect (Sxy) plays marker x→y — it picks which part of the break. Forward, backward if x>y (SFA = reverse), silent if equal.

So notes never remap to another slice of the break: note = pitch, SLC = region. Slice a kick, snare, and hat out of one WAV and play them as a kit.

Signature effect #2: TBL — Table (M8-style)

Schedule notes and effects on a per-tick basis. Ideal for arpeggios, fast retriggers, and delays — and for highly reusable effect combinations. In a table you can:

  • Arpeggios — C-4 at tick 00, E-4 at 04, G-4 at 08
  • Loops — jump backward with YRJ; it repeats until that channel plays a pattern note or OFF.
  • Retriggers — note at 00, X00 at 03 replays it every 4 ticks
  • Fractional delays — UDL80 delays a note by about half of a pattern row, or half of a table tick when used in a table.
  • Automation — pan/volume/vibrato/slice sweeps across ticks

XXJPYesYesIn patterns, jump to a pattern (Pattern mode) or the next active order for that pattern (Song mode). In a table, jump to another table.
YYRJYesYesJump to an absolute row in a pattern or tick in a table. A backward table jump loops until that channel plays a pattern note or OFF.
ZZTMYesYesIn patterns, set runtime BPM using a hexadecimal value (00 restores song BPM). In tables, set ticks per row (01–30 hex; 00 restores song setting).
